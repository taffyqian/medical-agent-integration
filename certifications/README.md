## 1. MIT Sloan × MIT Schwarzman College of Computing

### Implementing Agentic AI: Building Your Organizational Playbook
**Executive Program** | Aug 2026

**Capstone deliverable**: A board-level agentic AI adoption playbook for Huawei

- **WHAT** — Defined agentic AI on the AI continuum; applied three adoption realities; selected candidate workflow (AI Project Brain: end-to-end orchestration across contract, budget, and governance)
- **HOW** — Designed five building blocks (Perception · Action · Planning · Memory · Safety); build/buy/stack decision; human-in-the-loop threshold map; 3-week MVP scope; Agent Manager role; AgentOps metrics
- **SCALE** — Autonomy dial (5 levels); four safeguard layers (hard constraints · output verification · reversibility · escalation); portfolio-scale governance; non-human identity management; AI Bill of Materials
- Applied to a real Huawei use case integrating ISDP / MetaERP / iSales systems
